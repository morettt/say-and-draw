# SayAndDraw · 说画

通过训练qwen3.5 0.8b 指令模型。输入文字，模型用普通文字回复，或逐笔绘制手写内容。这里开放推理代码和网页界面。**当前权重只训练了单个数字 0～9**；字母、汉字和其他画面是项目的后续目标，当前版本还不能可靠生成。


## 运行原理

画图请求进入 Qwen3.5-0.8B 后，模型先回复一句文字，再生成 `<DRAW>` 和 16 个 `<M000>`～`<M255>` 编号。动作码本和笔画解码器将编号还原成 64 个二维点，网页按顺序画出线条。普通聊天请求直接输出文字。Qwen、码本和解码器的权重必须配套使用。

## 安装

建议 Python 3.12、NVIDIA GPU 和 CUDA 12.4。下面是本项目验证过的 PyTorch 版本；其他环境可能需要换成对应的 PyTorch 安装命令。

```bash
#部署环境
conda create -n saydraw python=3.12 -y
conda activate saydraw
#下载依赖
pip install torch==2.6.0 torchvision==0.21.0 --index-url https://download.pytorch.org/whl/cu124
pip install -r requirements.txt
```

CPU 也能尝试运行，速度会慢很多。此时可直接安装 `requirements.txt`，启动时加 `--device cpu`。

## 下载模型

在仓库根目录执行，权重会自动下载到 `models/`。再次运行会复用已下载的文件。

```bash
python download_model.py
```

模型地址：[morelle/SayAndDraw-v0.1](https://www.modelscope.cn/models/morelle/SayAndDraw-v0.1)。

## 启动网页

```bash
python app.py
```

打开 <http://127.0.0.1:6006/>，可以输入“请你画一个数字3”，也可以发送普通聊天消息。服务默认只监听本机；要让局域网设备访问，可加 `--host 0.0.0.0`。

接口是 `POST /api/generate`，请求示例：

```json
{"messages":[{"role":"user","content":"请你画一个数字3"}],"temperature":0.7}
```

画图回复含 `reply`、`tokens`、`strokes` 和 `elapsed_ms`；聊天回复的 `strokes` 为 `null`。`temperature: 0` 使用确定性选码，较高温度会增加变化，也可能降低画图质量。

## 当前限制

- 模型目前只学习单个数字 0～9，不能据此宣称可以画任意内容。
- 现有笔迹数据未单独编码抬笔位置。数字 4 和 5 使用预览版的固定抬笔位置；后续扩展到字母和多笔画图形时，需要训练显式的抬笔表示。
- 训练时的逐编号准确率只衡量编号预测，不能代替肉眼观察绘制质量。
- 本仓库只提供推理与操作界面，不包含训练数据和训练脚本。


# 接下来目标

1.解决llm不知道自己实际生成的数字是什么。
例如让模型自己生成一个数字。它写了一个数字，解码成图像是8的样子。你问模型生成了什么数字。模型回复3  这是因为模型没有过对于编号是什么数字的专项训练。目标是实现询问模型刚刚生成的数字是什么，模型可以正确的回答生成的数字是什么。同时如果可以。询问这个数字有哪些特点。例如数字8可能是上面大下面小。模型也能识别出来并告知。
2.更丰富的指令要求。例如：生成一个更宽的数字8 模型输出的数字8更加的扁平。 或者：生成一个更细的数字7  模型生成的数字则更窄
3.升级任务。让模型生成26个英文字母。包含大小写。
4.升级任务，让模型实现画画。例如：画一个小鸟。模型输出对应的数据编号。转换后是一个小鸟的样子
5.模型可以基于已经画好的图像二次修改。例如擦除用户告知的某个部位。或者增加某个部位的润色改动
