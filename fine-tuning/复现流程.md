# 小型 Transformer 数字和字母模型：开源复现说明
 
目标：输入一个数字或大写字母，生成 16 个 VQ 编号，再还原成笔画并显示。

## 模型分工

- AlignedVQ：把原始 XY 坐标压缩成 16 个编号。
- Causal Transformer：学习“字符 → 16 个编号”。
- StructuredStrokeDecoder：把 16 个编号对应的向量转换成笔画数量和 XY 坐标。

流程：

```text
原始 XY 数据 → VQ 编号 → Transformer → 16 个编号 → 结构化笔画 → 画布
```

## 数据

手写字母、数字训练数据放在：

```text
data/digits_all.npz
```

字符顺序固定为：

```text
0123456789NBACDEFGHIJKLMOPQRSTUVWXYZ
```

## 训练顺序

### 1. 训练 AlignedVQ

```bash
python train_aligned_vq.py
```

### 2. 训练平滑版 VQ

```bash
python train_aligned_vq_smooth.py
```

### 3. 用 VQ 编号训练 Causal Transformer

```bash
python train_causal_vq.py
```

参数：4 层、隐藏维度 128、4 个注意力头、前馈维度 512、batch 64、学习率 2e-4、最多 3000 步。

### 4. 训练结构化笔画解码器

```bash
python train_structured.py
```

它使用真实的分笔 XY 数据作为目标，学习输出笔画数量和每笔坐标。

### 5. 训练 Transformer 续训版本

```bash
python train_control.py
```

### 6. 评估

```bash
python evaluate_retrain.py
```

## 开源时必须满足

1. 所有训练脚本只读取本地 `data/`。
2. 不写服务器地址、服务器目录、SSH、密码或私有权重。
3. 发布 `digits_all.npz`，或者明确说明数据的公开下载地址和许可证。
4. 发布训练配置、随机种子和评估方法。
5. 不把 `VQ 编码器`称为解码器：生成时是查 VQ 码本向量，再交给结构化解码器。
